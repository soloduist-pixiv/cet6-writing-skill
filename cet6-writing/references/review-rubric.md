# 批改与模拟评估

## 训练量尺的身份

以下为本 Skill 自定义的 **0–15 分训练量尺**，便于追踪进步，不是官方评分细则或官方认证；没有经实考标定的预测能力。默认报约 2 分宽的区间（如 9–11/15），不是伪精确的小数。证据不充分时可加宽，缺题目时仅提供暂定的语言评价，不能给完整任务完成度结论。

先记录合规事实，再综合判断文章质量，不按“一个错扣一分”累加。不要将下表当机械加权公式。不要把 15 分量尺乘固定系数换成正式成绩，也不要声称每次超词数或未抄开头会受到某个未经核实的官方固定处罚。

| 观察维度 | 主要证据 |
|---|---|
| 任务完成 | 立场及必答要点，是否真正回答 how、why、advantages and measures 等要求 |
| 论证与内容 | 理由能否支持观点，解释是否具体，例子是否有用，是否重复和夸大 |
| 结构与衔接 | 段落功能、信息顺序、指代、连接的实际逻辑，避免只数连接词 |
| 语言准确与得体 | 影响理解的错误、错误频率、搭配和语域，简单正确表达也有价值 |
| 表达灵活性 | 准确基础上的句式变化和词汇精确性，不奖励堆砌 |

## 区间参考（教学描述）

| 训练分段 | 典型表现 |
|---|---|
| 13–15 | 充分回应任务，论证具体连贯，表达准确自然；少量小问题不妨碍交流 |
| 10–12 | 基本切题，结构清楚，有一定展开；语言偶有错误或搭配生硬 |
| 7–9 | 大意可懂但展开薄弱、要点可能缺失，语言或逻辑问题较多 |
| 4–6 | 内容和组织明显不足，频繁错误使理解吃力 |
| 1–3 | 相关内容极少，连贯表达非常有限 |
| 0 | 空白或没有可评估的有效英语作答；不能因一处硬性不合规直接归零 |

区间横跨分段边界很正常。严重跑题、要点遗漏、长度不足等会降低综合评价信心和完成度；说明影响，不编造官方封顶规则。文采好也不能抵消题目遗漏。不能把修订稿的优点倒算给原稿。

名言评论另查：是否解释题面特定含义与比喻、例子是否支持它、是否把格言绝对化；这些是内容与论证评价。Test 20–30 未以引文开头不构成违规。Test 19 漏写现状或措施才是任务遗漏；不能因没有单列“重要性”而扣任务完成度。批改用到教材署名或人物故事时区分“未核实”与“已证伪”，不要未经查证宣判为事实错误。

## 分类示例

| 原表达 | 类别 | 建议与理由 |
|---|---|---|
| Eating too much food without exercise exert a negative impact... | 错误 | exert → exerts，动名词短语作单数主语。论点是否夸大另评 |
| engaging in their smartphones | 不够自然 | using their smartphones；engage in 通常接活动，不直接接设备 |
| remember that... | 可选优化 | keep in mind that... 可用，但 remember 原本正确且更短 |
| complete daily work efficiently → on time | 语义变化提醒 | efficiently 是高效，on time 是按时；不能仅为避免重复把它们视为等义替换 |
| We can solve the problem by improving our ability. | 可选优化/内容不足 | 需联系上下文明确什么能力、如何改进；句法本身无错 |

表中只有实际出现的问题才进入用户的批改表。错误类别有疑义时说明判断依据，不将偏好包装为规则。

## 紧凑输出示意

“原稿 162 词（工具口径）；开头一致；措施要点缺失。模拟评估约 8–10/15，非官方认证，不能预测实考成绩。主要依据：语言基本可懂，但题目要求的解决措施没有展开。”

然后列具体证据与纠改；无需每个维度都给数字。教学重点通常选一个反复出现的语言问题和一个内容问题。
