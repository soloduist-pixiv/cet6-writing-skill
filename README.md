# CET-6 Writing Skill｜六级英语写作

用于大学英语六级作文的批改、润色、撰写和分步练习。中文讲解、英文成文。

- 五步法：审题 → 列框架 → 快速成文 → 润色 → 终稿。
- 区分错误、不够自然和可选优化；保留作者原意。
- 检查 150–200 词及题目指定开头，区分指定首句与名言评论。
- 覆盖 30 个教材练习主题，包含名言评论、论据展开及材料勘误。
- 提供无第三方依赖的 Python 计词工具。

## 安装

下载仓库，将 `cet6-writing/` 整个文件夹复制到 `~/.codex/skills/`，开始新聊天后调用 `$cet6-writing`。也可将此文件夹打包导入兼容 Skill 的工具。

## 使用

> 请用 $cet6-writing 批改以下六级作文，区分错误、不够自然和可选优化，给出保留原意的修订稿。题目：…… 作文：……

> 请用 $cet6-writing 按 Test 24 写一篇 150–200 词的名言评论，先解释比喻，再用具体例子展开。

> 请用 $cet6-writing 带我审题和列框架，先不要直接写全文。

## 计词

在 `cet6-writing/` 目录运行：

```sh
python scripts/check_essay.py essay.txt
python scripts/check_essay.py essay.txt --opening-file opening.txt
```

输入为 UTF-8 纯正文，不含标题及讲解。工具口径不是官方计词程序，也不检查内容覆盖和语言质量。

## 评估与资料说明

评分为自定义 0–15 训练量尺的模拟评估，非官方认证，不保证或预测实考成绩。考试要求以当次完整题面为准。

本项目提炼学习材料中的写作方法，包含原创教学指导和示例，不附原书照片、原始 OCR 或整篇教材范文。部分题面短句与引文用于教学索引和评论，第三方材料及引语不因本项目许可而重新授权。原教材书目信息尚未确认，具体边界见 `cet6-writing/references/material-notes.md`。
